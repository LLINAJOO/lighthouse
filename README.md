# Light House

Уютная пиксельная игра о последней семидневной смене смотрителя маяка.

**Играть:** https://llinajoo.github.io/lighthouse/

## Как устроен проект

```
index.html            разметка страницы и порядок подключения скриптов
css/style.css         все стили интерфейса
fonts/monocraft.woff2 пиксельный шрифт (подмножество Monocraft)
js/
  core.js             утилиты, тайлы, генерация карт острова и комнат
  render.js           палитра, отрисовка земли, воды, деревьев, иконки
  audio.js            музыка и звуки (Web Audio, всё генерируется на лету)
  world.js            состояние игры, дни, дела, предметы, диалоги, объекты острова
  island-life.js      гости на лодках, кот, травы, ремесло, скамейки, подзорная труба, достижения
  atlas-docs.js       атлас, рыбалка, птицы, письма и фото, инспектор
  boat-islets.js      «Надежда», плавание, Тюлений камень, Птичий базар, Нюра
  sprites/            спрайты: птицы, люди, рыбы, кот, мольберт и общий контур
  main.js             игровой цикл, управление, интерфейс, освещение, финал
  soul/               карта и подсказки, дневник, письма, тихие моменты, выборы, ночные события, звуки, финал недели
  dev-panel.js        тестовая панель (адрес с #test или набрать «тест» в игре)
  boot.js             запуск
tools/build_single.py собирает всю игру в один HTML-файл (dist/lighthouse.html)
```

Скрипты подключаются обычными `<script>` по порядку: каждый файл пользуется только тем, что загружено выше него.
